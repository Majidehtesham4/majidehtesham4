# فیلم‌های معرفی و آموزشی

فیلم از خود برنامه ساخته می‌شود، روی یک پایگاه آزمایشی با داده‌ی نمونه، نه روی ERP عملیاتی.

1. `seed_demo.py`: داده‌ی نمونه (شرکت، مشتری، کالا، فاکتور، چک) در یک پایگاه آزمایشی که `veron_account_iran`،
   `veron_cheque` و `veron_moadian` در آن نصب است:
   `odoo shell -d <پایگاه آزمایشی> < seed_demo.py`
2. `capture.js`: برنامه را با Playwright باز می‌کند، فاکتور می‌سازد، چک و گزارش‌ها را باز می‌کند و از هر قدم
   تصویر با وضوح دوبرابر و جای دکمه‌ها و فیلدها (`shots.json`) می‌گیرد:
   `node capture.js <پوشه‌ی تصویرها>` (برنامه روی localhost:8069، پایگاه `vid`، کاربر admin)
3. `main.py`: فیلم ۱۰۸۰p با زوم دوربین، مکان‌نما و کلیک، نورافکن روی بخش‌ها، ذره‌بین، زیرنویس فارسی، کارت فصل‌ها،
   لوگو و موسیقی و صداهایی که خود `audio.py` می‌سازد (بدون حق نشر کسی):
   `python3 main.py <پوشه‌ی تصویرها>` → `build/erp-veron-accounting.mp4`
   با `FRAMES=150,600 python3 main.py ...` فقط همان فریم‌ها برای بازبینی ساخته می‌شوند.

سناریوی هر فیلم در `storyboard()` در `main.py` است: هر صحنه مدت، تصویرها، کلیدهای دوربین (x، y، زوم)، مسیر
مکان‌نما، کلیک‌ها، نورافکن‌ها، ذره‌بین‌ها و زیرنویس‌ها را دارد. ابزار لازم: Python با Pillow و numpy، ffmpeg، Node با Playwright.
