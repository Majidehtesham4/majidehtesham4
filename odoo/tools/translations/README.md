# ترجمه‌ی فارسی ماژول‌ها

فایل‌های `addons/veron_core/i18n_modules/<ماژول>.po` (ماژول‌های OCA و خود Odoo که فارسی کامل نداشتند) و رشته‌های
وب در `addons/veron_core/i18n/fa.po` با این ابزارها ساخته می‌شوند. `veron_core` آن‌ها را هنگام نصب و به‌روزرسانی
هر ماژول در پایگاه داده می‌گذارد و فقط جاهای خالی را پر می‌کند.

- `manual/<ماژول>.json`: ترجمه‌های دستی، `{"متن انگلیسی": "ترجمه"}`. **ترجمه‌ها این‌جا اصلاح یا اضافه می‌شوند.**
- `missing.py`: برای هر ماژول نصب‌شده، عبارت‌های فایل `.pot` که در `fa.po` خود ماژول ترجمه ندارند.
- `memory.py`: ترجمه‌ی همان عبارت در فایل‌های فارسی دیگر Odoo و OCA (حافظه‌ی ترجمه)، و آنچه دستی مانده است.
- `build.py`: ساخت فایل‌های `.po`؛ عبارتی که `%s`، `%(name)s`، `{...}` یا نام تگ HTML را جا بیندازد کنار گذاشته
  و گزارش می‌شود.

پوشه‌ی کار (`S`) این‌ها را دارد: `t/odoo` (همین پوشه‌ی `odoo` با `oca` گرفته‌شده)، `tr/odoo_pot` و `tr/odoo_fa`
(فایل‌های `.pot` و `fa.po` خود Odoo از ایمیج `odoo:19.0`)، و `tr/manual` (همین پوشه‌ی `manual`).

```bash
python3 missing.py $S/t/odoo $S/tr/todo <ماژول‌های نصب‌شده>
python3 memory.py $S
python3 build.py $S <مسیر odoo>/addons/veron_core/i18n_modules
```
عبارت‌های داخل کد (پیام‌های پایتون و متن‌های وب) را هم `veron_core/models/code_translations.py` از همین فایل‌ها
می‌خواند. نمونه‌متن‌ها کنار گذاشته شده‌اند.
