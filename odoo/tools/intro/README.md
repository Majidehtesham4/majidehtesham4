# اینتروی VERON ERP

دو اینتروی لوگو، ساخته‌شده با مرورگر (Chromium) و ffmpeg. لوگو خط‌به‌خط بازسازی شده تا هر خط جدا روشن و متحرک شود.

| صحنه | زمان | شرح |
|---|---|---|
| `signal` | ۸ ثانیه | نقطه‌ی نور و پینگ، کمان‌های سیگنال یکی‌یکی، کشیده شدن خطوط V و دایره‌ها، موج نور، نوشته با نوار نور قرمز |
| `draw` | ۸٫۵ ثانیه | کشیدن لوگو با قلم نوری (دایره‌ها، V، کمان‌ها)، ظاهر شدن کاشی، نوشته با برق نور روی فلز |
| `energy` | ۷٫۵ ثانیه | خطوط نور از گوشه‌ها، برخورد و انفجار نور، بیرون آمدن لوگو با لرزش، نوشته با صدای بم و چرخیدن نور قرمز دورش |
| `metal` | ۹ ثانیه | نزدیک شدن آهسته‌ی دوربین، نور قرمز از پشت لوگو، روشن شدن خطوط مثل لامپ نئون، بازتاب سفید روی فلز، مه قرمز |
| `pulse` | ۳٫۶ ثانیه | دو ضربان نور از مرکز لوگو، نوشته کنار لوگو؛ برای شروع ویدیوهای آموزشی |
| `network` | ۷٫۹ ثانیه | لوگوی شبکه‌ای: هشت ماژول اصلی (Sales، CRM، Purchase، Inventory، Manufacturing، HR & Payroll، Accounting، AI Agents) در دایره با آیکون و نام از بالا می‌افتند و روی گره‌های V می‌نشینند، بقیه‌ی گره‌ها مثل باران، خطوط شبکه کشیده می‌شوند، موج نور از نوک V بالا می‌رود |

## ساختن

```bash
cd odoo/tools/intro
node render_video.js signal signal_v.mp4 60          # تصویر
python3 audio_intro.py signal signal.wav              # صدا (ساخته‌شده از موج سینوسی و نویز، بدون حق نشر کسی)
ffmpeg -i signal_v.mp4 -i signal.wav -c:v copy -c:a aac -b:a 256k -shortest veron-intro-signal.mp4
node stills.js metal 2.4 4.8 8.0                       # چند فریم برای بررسی
```

- نیاز: Node با Playwright (Chromium)، Python 3 با numpy، ffmpeg.
- زمان‌بندی، رنگ‌ها و اندازه‌ها در `intro.html` است (`signal()` و `metal()`).
- نوشته‌ی VERON ERP از روی طرح خودش ماسک شده است (`wordmark.py`)؛ نور قرمز به‌صورت خطی دور بیرون حروف است و می‌تواند دور کلمه بچرخد.

## اینتروی «حکاکی با لیزر» (۳ بعدی، ۱۲ ثانیه)

لیزر لوگو را روی صفحه‌ی فولاد مشکی حک می‌کند: شیارها هندسه‌ی واقعی زیر سطح‌اند و فلز مذاب در آن‌ها از سفید و زرد و نارنجی تا قرمز لوگو سرد می‌شود. جرقه‌ها می‌پرند و روی صفحه برمی‌گردند، دود بلند می‌شود و هوا از گرما موج برمی‌دارد. دوربین اول از نزدیک دنبال نور می‌رود، بعد بالا می‌رود تا کل لوگو دیده شود، و یک لیزر کوچک خط زیر ERP را حک می‌کند. ۲۴ فریم با تاری حرکت (دو لحظه در هر فریم)، عمق میدان، درخشش، دانه و حاشیه‌ی رنگی لنز.

```bash
cd odoo/tools/intro
npm pack three@0.170.0 && tar xzf three-0.170.0.tgz      # three.js در پوشه‌ی package
python3 -m http.server 8765 --bind 127.0.0.1 &            # ماژول‌ها از روی دیسک باز نمی‌شوند
node stills_laser.js 0.8 2.4 6.5 11                        # چند فریم برای بررسی
node render_laser.js laser_v.mp4 24                        # تصویر (حدود نیم ساعت با پردازنده)
python3 laser_audio.py laser.wav                           # صدا
ffmpeg -i laser_v.mp4 -i laser.wav -c:v copy -c:a aac -b:a 256k -shortest veron-intro-laser.mp4
```
