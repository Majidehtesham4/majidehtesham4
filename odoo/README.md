# نصب آزمایشی Odoo 19 (Community)

برای بررسی Odoo کنار ERP-VERON. سیستم فعلی دست نمی‌خورد: ERP-VERON روی پورت 8080 می‌ماند و Odoo روی 8069 اجرا
می‌شود، با پایگاه داده‌ی جدای خودش.

## فضای لازم
- ایمیج Odoo 19: حدود ۳٫۳ گیگ
- ایمیج PostgreSQL 16: حدود ۰٫۶ گیگ
- پایگاه داده‌ی خالی به زبان فارسی: حدود ۱۰۰ مگ (با ماژول‌ها و داده‌ی نمونه تا ۱ گیگ)
- **جمع:** حدود ۴ تا ۵ گیگ. پیشنهاد: دست‌کم ۱۰ گیگ فضای خالی.

## نصب (یک بار)
۱. Docker Desktop را باز کنید و صبر کنید سبز شود.

۲. نسخه‌ی تازه‌ی مخزن را بگیرید و اجرا کنید:
```powershell
cd D:\majidehtesham4
git pull
cd odoo
powershell -ExecutionPolicy Bypass -File .\odoo.ps1 start
```
بار اول دانلود ایمیج‌ها بسته به اینترنت چند دقیقه طول می‌کشد.

۳. در مرورگر `http://localhost:8069` را باز کنید. صفحه‌ی ساخت پایگاه داده می‌آید:

| فیلد | مقدار |
|---|---|
| Master Password | `veron-trial-change-me` (همان که در `config/odoo.conf` است) |
| Database Name | `trial` |
| Email | نام کاربری مدیر، مثلاً `admin` |
| Password | رمز مدیر |
| Language | **Persian / فارسی** |
| Country | **Iran** |
| Demo data | اگر می‌خواهید با داده‌ی نمونه ببینید، تیک بزنید |

۴. وارد شوید. از منوی «برنامه‌ها» (Apps) ماژول‌ها را نصب کنید، مثلاً فروش، خرید، انبار، حسابداری و CRM.

## ماژول نمونه‌ی خودمان (`addons/veron_base`)
یک ماژول کوچک که نشان می‌دهد برنامه‌نویسی روی Odoo چطور است:

- مدل «یادداشت» با فیلدها و یک فیلد محاسبه‌شده؛
- فهرست و فرم؛
- دکمه‌ی «انجام شد»؛
- منوی ERP-VERON.

**نصب:** «برنامه‌ها» ← «به‌روزرسانی فهرست برنامه‌ها» ← جست‌وجوی `ERP-VERON` ← «نصب».

## برنامه‌نویسی
- همه‌ی کدهای شما در پوشه‌ی `addons` است، روی خود ویندوز. خود Odoo تغییر داده نمی‌شود.
- هر ماژول یک پوشه است با `__manifest__.py`. نمونه‌اش `veron_base` است.
- **تغییر در فرم‌ها و گزارش‌ها (XML):** با تازه‌کردن صفحه دیده می‌شود (حالت `--dev=xml`).
- **تغییر در کد پایتون یا فیلدها:** ماژول را به‌روز کنید:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\odoo.ps1 update veron_base trial
  ```
- **برای مطالعه‌ی کد خود Odoo** (اختیاری، حدود ۱ گیگ)، فقط همان ورژن را بگیرید، بیرون از این پوشه:
  ```powershell
  git clone --depth 1 --branch 19.0 https://github.com/odoo/odoo.git D:\odoo-src
  ```
  آن را فقط برای خواندن و تکمیل خودکار در VS Code استفاده کنید و چیزی در آن تغییر ندهید.

## دستورهای روزمره
```powershell
.\odoo.ps1 start    # روشن کردن
.\odoo.ps1 stop     # خاموش کردن (داده‌ها می‌مانند)
.\odoo.ps1 logs     # دیدن گزارش اجرا و خطاها
.\odoo.ps1 update veron_base trial   # به‌روز کردن ماژول بعد از تغییر کد
.\odoo.ps1 remove   # حذف کامل (پوشه‌ی addons می‌ماند)
```

## حذف کامل و برگرداندن فضا
۱. `.\odoo.ps1 remove` را اجرا کنید (تأیید با `yes`).

۲. Docker Desktop فضای آزادشده را خودش به ویندوز پس نمی‌دهد. برای برگرداندنش:
- Docker Desktop را ببندید (Quit).
- در PowerShell با دسترسی Administrator این را بزنید:
  ```powershell
  wsl --shutdown
  ```
- در Docker Desktop: Settings ← Resources ← Disk image ← «Clean / Purge data» یا «Compact».

  نسخه‌های جدید Docker Desktop گزینه‌ی کم‌کردن حجم دیسک را دارند؛ در نسخه‌های قدیمی‌تر می‌شود فایل
  `docker_data.vhdx` را با `diskpart` کوچک کرد. اگر لازم شد، روشش را قدم‌به‌قدم می‌گویم.

## چند نکته
- **تاریخ‌ها:** Odoo 19 در زبان فارسی تاریخ‌ها را شمسی نشان می‌دهد (مثلاً «۳ آبان»).
- **حساب‌ها و مالیات ایران:** دفتر حساب‌های ایرانی، چک و مالیات بر ارزش افزوده‌ی ایران در Odoo آماده نیست و باید ماژولش
  ساخته یا پیدا شود. کارهای ERP-VERON (نمایشگاه خودرو، اقساط، سرمایه‌گذاران) هم در Odoo وجود ندارد.
- **Odoo 20 هم منتشر شده،** ولی تازه است. برای بررسی، ۱۹ پایدارتر است. ورژن در `docker-compose.yml` ثابت شده
  (`odoo:19.0`) و فقط با عوض کردن همان خط تغییر می‌کند.
- **رمزها:** این نصب فقط برای آزمایش است. پیش از وارد کردن اطلاعات واقعی، Master Password در `config/odoo.conf` و
  رمز پایگاه داده را عوض کنید.
